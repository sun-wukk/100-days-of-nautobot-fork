# 应用回顾与展望

恭喜你坚持到了第 60 天！

今天我们将稍作休息，回顾我们学到的内容，并回到那些第一次可能不清楚的日子。

从第 61 天开始，我们将深入研究 Django 和 Nautobot 的不同技术领域。

## 第 41-59 天回顾

很难想象我们在第 41 天只是安装和卸载 Nautobot 应用，而到了第 59 天，我们已经在处理功能性的 Nautobot 应用了。

让我们回顾一下我们做了什么：

- 第 41 天：安装和卸载 PyPI 上的 Nautobot Apps。
- 第 42-43 天：使用 Nautobot Cookiecutter 搭建 Nautobot 应用开发框架并学习文件结构。
- 第 44-45 天：我们构建了一个可归因的应用包并将其安装到另一个实例上。
- 第 46-49 天：我们暂时离开 Nautobot，构建一个 Django 应用，从创建数据库模型，到构建视图、模板，最后添加输入表单。
- 第 50-59 天：我们使用 Nautobot 仓库的 example_app 来构建一个新功能，学习数据库模型、URL 调度、视图和模板之间的交互。

如果目前仍有不清楚的日子，今天是回顾和加深理解的好日子。

## 展望第 61-80 天

从第 61 天开始，下一个部分将花更多时间在 Nautobot 应用的主要组件上。例如，我们将花几天时间在数据库模型上，再花更多时间在 Django/Nautobot 视图上，等等。
